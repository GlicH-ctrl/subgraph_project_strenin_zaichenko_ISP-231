#  Система поиска частых подграфов

> Учебный проект по дисциплине "Интеллектуальный анализ данных"  
> Авторы: Стренин Денис, Заиченко Андрей | Группа: ИСП-231  
> Язык: Rust  | Версия: 0.4.0

##  Описание
Программа реализует базовый алгоритм поиска частых подграфов (Frequent Subgraph Mining) в наборе ориентированных графов. 
Данные вводятся **интерактивно** через консоль, программа автоматически валидирует ввод, строит структуру графов и находит рёбра, встречающиеся чаще заданного порога.

##  Основные возможности
-  **Интерактивный ввод**: графы вводятся прямо в терминале по очереди
-  **Лимиты системы**: максимум **10 графов**, в каждом до **5 вершин**
-  **Умная валидация**: проверка на пустой ввод, минимальное кол-во вершин (2), макс. лимиты
-  **Авто-построение рёбер**: вершины автоматически соединяются в цепочку `v1→v2→v3...` с меткой `link`
-  **Гибкий порог**: параметр `--min-support` настраивается при запуске
-  **Быстрый выход**: пустая строка завершает ввод графов

##  Запуск и использование

### 1. Компиляция и запуск
```bash
# Стандартный запуск (интерактивный режим)
cargo run

# Запуск с кастомным порогом поддержки (например, 3)
cargo run -- --min-support 3
# или коротко:
cargo run -- -s 3
