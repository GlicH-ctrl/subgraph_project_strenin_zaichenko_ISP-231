##  Описание

Программа реализует базовый алгоритм поиска частых подграфов (Frequent Subgraph Mining) в наборе ориентированных графов с метками.

### Текущая функциональность:
-  Работа с ориентированными графами (библиотека `petgraph`)
-  Метки на вершинах и рёбрах
-  Поиск частых рёбер по меткам вершин
-  Настройка порога поддержки (`min_support`) через CLI
-  Тестовые графы для отладки

##  Запуск

```bash
# Скомпилировать проект
cargo build --release

# Запустить с параметрами по умолчанию (min_support = 2)
./target/release/subgraph_mining

# Запустить с кастомным порогом
./target/release/subgraph_mining --min-support 3

# Или через cargo
cargo run -- --min-support 1
